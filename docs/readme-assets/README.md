# README showcase assets

Screenshots for the root [README.md](../../README.md) live here — one folder per app.

## Layout

```text
readme-assets/
  <app-id>/
    screenshots/
      *.png   # 3–6 phone screenshots, already cropped
```

## `01_rn_basics`

Add PNGs under `01-rn-basics/screenshots/`:

| File | Screen |
|------|--------|
| `list.png` | Pokémon list (landing tab) |
| `detail.png` | Detail — artwork, types, defenses |
| `detail-stats.png` | Detail — stats scroll |
| `favorite.png` | Favorite tab |
| `map.png` | Map pin sheet |
| `camera.jpg` | Camera sticker compose |

Keep width around 1290px (iPhone logical width × 3) or export from the simulator as-is; the README scales them to ~200px wide in a row.

Videos stay on YouTube; link only in the root README.
