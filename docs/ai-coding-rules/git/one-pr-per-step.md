# One pull request per step

Open one pull request for each assignment step. A bonus feature gets its own extra pull request. Leave a step unmerged until it is reviewed, and open a pull request only when the owner asks for one.

## Good

```text
Step: Pokémon list with infinite scroll.
PR: "List Pokémon with infinite scroll"
Photo capture is a separate PR, opened after the owner asks for that bonus.
```

## Bad

```text
The whole list step lands on main with no review, or a bonus-feature PR opens before the owner asks for it.
```
