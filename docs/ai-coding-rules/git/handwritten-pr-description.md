# Hand-written pull request description

The pull request body is two or three sentences written by the owner. It says what the pull request does and which decisions were made. Agents write that description, merge, or push only when the owner explicitly asks.

## Good

```text
Owner writes: "This adds the Pokémon list with infinite scroll. I kept the fetch in the screen hook so the route file stays thin."
The branch stays unpushed and the pull request stays open until the owner asks otherwise.
```

## Bad

```text
An agent drafts the pull request body, pushes the branch, and squash-merges without the owner asking.
```
